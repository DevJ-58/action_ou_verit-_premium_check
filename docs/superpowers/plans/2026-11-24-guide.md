# Guide pas à pas et « Comment jouer » — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A spotlight tour that highlights one element at a time and says what it is for, on Home, the room lobby and the room game, plus a "Comment jouer" rules page.

**Architecture:** Elements get a `data-tour="<id>"` attribute. A tour is a list of `{ target, title, text }` steps (`src/features/guide/tours.ts`). `<Tour>` measures the target, draws a dimmed overlay with a hole and a bubble, and skips missing targets. `useAutoTour(name)` starts a tour the first time a screen is seen; seen tours live in `settingsStore.toursSeen`. `<TourButton>` ("?") restarts it. `/regles` is a lazy route.

**Tech Stack:** React 19, TypeScript strict, Tailwind v4, Zustand, motion, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-24-guide-design.md`

## Global Constraints

- No new dependency. Initial JS stays ≤ 200 KB (`npm run check:bundle`): `Tour` and `RulesScreen` are lazy-loaded.
- All copy in `src/i18n/fr.ts` and `src/i18n/en.ts` (key group `tour` and `rules`), French first, tutoiement.
- The tour never blocks: "Passer" always visible, Escape closes, a seen tour never auto-starts again.
- Accessible: bubble `role="dialog"` `aria-modal="true"` labelled by its title, focus on "Suivant", trapped with `useFocusTrap`.
- No horizontal overflow at 320 px (existing `tests/e2e/responsive.spec.ts` rules).

## Review Focus

- Target not on screen (e.g. mic hidden, no live): the step is skipped, counter counts only shown steps.
- Target below the fold: it is scrolled into view (`scrollIntoView({ block: 'center' })`) before measuring.
- Window resize / rotation / keyboard during the tour: the hole follows (re-measure on `resize` and `scroll`).
- Bubble near the bottom of a 568 px screen: it goes above the target and stays on screen.
- Tour started then screen changes (game moves to next phase): tour closes if its current target disappears and none after remain.
