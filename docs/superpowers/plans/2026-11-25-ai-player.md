# Axis, le joueur IA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A built-in fictional player, Axis, who joins rooms, plays every step, votes, reacts and talks in the chat.

**Architecture:** Axis is a room `Member` (`id: 'bot-axis'`). The host's phone plays him: a pure planner `planBot(room, botId)` returns the next move (an intent body, a delay, an optional chat line and mood); `useBotDriver` (host only) schedules it and applies it with `roomStore.actAs(botId, body)`. His chat lines live in `room.botChat` (written by the host) and are merged into each phone's chat. His face comes from six cropped images with moods.

**Tech Stack:** React 19, TypeScript strict, Zustand, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-25-ai-player-design.md`

## Global Constraints

- No new dependency; no SQL migration; initial JS ≤ 200 KB (bot planner and lines lazy-loaded with the room game).
- Axis is free (no Premium crown), always labelled « IA », never host, never a friend target.
- Random choices seeded by turn (`${game.id}:${round}:${answererId}:${salt}`) so re-planning never changes his mind.
- Delays 1 500–4 000 ms before each move; at most one chat line per 8 000 ms (except a direct reply).
- FR + EN copy, ≈15 lines per situation.

## Review Focus

- Host phone leaves or sleeps: the next human host resumes Axis (driver runs wherever `role === 'host'`).
- Only the host and Axis remain and the host leaves: the room closes; Axis never becomes host.
- Axis is the answerer and nobody else can vote (solo game, `flow: 'everyone'`): the human votes; Axis completes after a verdict.
- The room is full (6/12): « Ajouter Axis » is disabled.
- Axis in `online`: never shown as away, never gets « passer le tour de… ».

### Task 1: Axis identity and face
**Files:** Create `src/content/axis.ts` (`AXIS_ID = 'bot-axis'`, `isBot(id)`, `axisMember(): Member`, `AXIS_FACES` 6 images, `type AxisMood = 'happy'|'talking'|'calm'|'cheeky'|'doubt'|'laugh'`, `axisFace(mood)`), `src/assets/axis/axis-{1..6}.webp` (done). Modify `src/design-system/Avatar.tsx`: `avatarId === 'axis'` renders `<AxisFace mood>` (mood from `useAxisMood()` store in `src/features/bot/axisMood.ts`; talking cycles 2→3→1 for 2 s). Tests: `axis.test.ts` (isBot, member shape), `Avatar.test.tsx` (axis renders img named Axis; talking mood cycles).

### Task 2: Room support
**Files:** `src/features/room/types.ts` (Intent `{type:'bot'; on:boolean}`; `RoomState.botChat?: ChatMessage[]` (last 20, each with `mood`)), `applyIntent.ts` (host-only, lobby-only, capacity, single Axis; removing Axis in lobby), `roomStore.ts` (`actAs(botId, body)` host-only for bot members; `say(botId, text, mood)` appends to `botChat`; `online` always includes bot members; successor/leave skip bots; host leaving with only bots left ends the room), `authorize.ts` unchanged. Tests in `src/features/room/bot.test.ts`.

### Task 3: The planner and lines
**Files:** `src/features/bot/planBot.ts` (`planBot(room: RoomState, botId: string, now: number): BotMove | null`, `BotMove = { delayMs; intent?: IntentBody; say?: { text; mood }; react?: EmojiName }`), `src/features/bot/lines.ts` (FR/EN lines by situation, `line(kind, seed, vars, lang)`), `src/features/bot/seeded.ts`. Rules: ready → SPIN after 8 s if nobody did; choosing (Axis answers) → CHOOSE_KIND; proposing (not answerer, not proposed) → PROPOSE a system dare of the turn kind in the room's categories within the answerer's limits; picking (Axis answers) → PICK_PROPOSAL; challenge (Axis answers): ANSWER (truth answer or dare story) then COMPLETE once a verdict exists, or SKIP 10% if skips left; challenge (other answers, no vote from Axis): VOTE ok 90% after the answer or 6 s; finished → say a line once. Tests `planBot.test.ts` (one per rule + determinism + never acts for others).

### Task 4: Driver and chat
**Files:** `src/features/bot/useBotDriver.ts` (host only; one timer for the next move; re-plans on room change; applies via `actAs`/`say`/react; replies to human chat messages mentioning “axis” or greeting, rate-limited), `src/features/chat/chatStore.ts` (`receive(message)`), `RoomGameView.tsx` and lobby: mount driver; merge `room.botChat` into chat. Tests `useBotDriver.test.tsx` with fake timers (plays a full solo turn), chat merge test.

### Task 5: UI
Home `EntryLink` « Jouer avec l'IA » → `/salon/nouveau?ia=1` (adds Axis right after creation); lobby host button « Ajouter Axis » / « Retirer » in `MemberList` (disabled when full); « IA » badge in MemberList, players sheet, table, chat bubble; `PublicProfileSheet` shows Axis card (bio, no friend button); home guide gets an « IA » step. Tests in the respective test files.

### Task 6: E2E, screenshots, changelog
`tests/e2e/axis.spec.ts`: one phone plays a full 1-round game with Axis (spin, choose, propose, verdict, Axis answers and completes, chat line visible). Screens 320/375/1280. Changelog; merge to main.
